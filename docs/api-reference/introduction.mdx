## Welcome

Welcome to the Unmai.ai API documentation. Our API provides comprehensive tools for content verification, including fact-checking, deepfake detection, and safety assessment.

## Authentication

Currently, the API endpoints are public or protected via Google Cloud IAM when deployed. For local development, no authentication is required.
