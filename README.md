## **Technology Architecture**

### **Frontend Infrastructure**
```yaml
Framework: Next.js 15 (App Router Architecture)

Styling: Tailwind CSS + shadcn/ui Components
Icons: Radix UI + Lucide React Library
```

## **Getting Started**

### **Prerequisites**

| **Requirement** | **Version** | **Purpose** |
|:----------------|:------------|:------------|
| **Node.js** | `18.0+` | Runtime environment |
| **Package Manager** | `npm/yarn/pnpm` | Dependency management |
| **Google Cloud Account** | `Active` | Service authentication |
| **Git** | `Latest` | Version control |
| **Google Cloud CLI** | `Latest` | Deployment and service management |

### **Installation**
```bash
# Clone the repository
git clone https://github.com/TamizhSK/Unmai.ai.git
cd Unmai.ai

# Install dependencies for all packages
npm run install:all

# Configure environment variables
# backend/.env - Google Cloud credentials & API keys
# frontend/.env.local - Frontend configuration variables

# Start development servers
npm run dev
```

### **Environment Configuration**

#### **Backend Configuration** (`backend/.env`)
```env
# Google Cloud Project
GOOGLE_CLOUD_PROJECT_ID=your-project-id
GOOGLE_APPLICATION_CREDENTIALS=path/to/service-account-key.json

# API Keys
VERTEX_AI_API_KEY=your-vertex-ai-key
CLOUD_VISION_API_KEY=your-vision-api-key

# Database
FIRESTORE_DATABASE_ID=your-database-id

# Server Configuration
PORT=8080
NODE_ENV=development
```

#### **Frontend Configuration** (`frontend/.env.local`)
```env
# API Endpoints
NEXT_PUBLIC_API_URL=http://localhost:8080
NEXT_PUBLIC_APP_URL=http://localhost:3000

# Feature Flags
NEXT_PUBLIC_ENABLE_ANALYTICS=false
NEXT_PUBLIC_ENABLE_DEBUG=true
```

## **API Documentation**

### **Available Endpoints**

| **Endpoint** | **Method** | **Description** |
|:-------------|:-----------|:----------------|
| `/api/verify/text` | POST | Verify text content for misinformation |
| `/api/verify/image` | POST | Analyze image for manipulation |
| `/api/verify/video` | POST | Detect deepfakes in video content |
| `/api/verify/audio` | POST | Authenticate audio recordings |
| `/api/verify/url` | POST | Check URL credibility and safety |
| `/api/analyze/source` | POST | Verify source authenticity |
| `/api/health` | GET | Service health check |

### **Example API Request**
```bash
curl -X POST https://unmai-ai.run.place/api/verify/text \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Content to verify",
    "language": "en"
  }'
```

## **Contributing**

We welcome contributions that enhance our mission of combating misinformation through technology.

### **Development Workflow**

1. **Fork** the repository
2. **Create** a feature branch (`git checkout -b feature/enhancement-name`)
3. **Implement** your changes with comprehensive tests
4. **Ensure** all tests pass (`npm run test`)
5. **Validate** code quality (`npm run lint && npm run typecheck`)
6. **Commit** your changes (`git commit -m 'feat: add comprehensive feature description'`)
7. **Push** to your fork (`git push origin feature/enhancement-name`)
8. **Submit** a pull request with detailed description

### **Code Quality Standards**

| **Standard** | **Requirement** |
|:-------------|:----------------|
| **TypeScript** | Strict mode enabled, no implicit any |
| **Testing** | Unit tests for new features (80% coverage minimum) |
| **Documentation** | JSDoc comments for public APIs |
| **Code Style** | ESLint + Prettier compliance |
| **Commits** | Conventional Commits specification |
| **PR Reviews** | Minimum one approval required |

### **Commit Message Format**
```
<type>(<scope>): <subject>

<body>
```

## **Deployment**

### **Production Deployment**
```bash
# Build production images
npm run build

# Deploy to Cloud Run
npm run deploy

# Deploy with custom configuration
gcloud run deploy unmai-ai \
  --source . \
  --platform managed \
  --region us-central1 \
  --allow-unauthenticated
```

### **Environment Variables for Production**

Ensure all production environment variables are set in Google Cloud Secret Manager:
- `GOOGLE_CLOUD_PROJECT_ID`
- `VERTEX_AI_API_KEY`
- `FIRESTORE_DATABASE_ID`
- Additional service-specific credentials
